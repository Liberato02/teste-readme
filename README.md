# 🎮 Soul Game | TM Consulting

Projeto desenvolvido para o Challenge da FIAP em parceria com a SoulUp.

A proposta do projeto é utilizar elementos de gamificação para incentivar o engajamento dos usuários através de desafios, recompensas e participação ativa dentro da plataforma.
